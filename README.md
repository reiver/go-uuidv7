# go-uuidv7

Package **uuidv7** implements **UUIDv7**, for the Go programming language.

I.e., **UUID** version 7.

## Documention

Online documentation, which includes examples, can be found at: http://godoc.org/github.com/reiver/go-uuidv7

[![GoDoc](https://godoc.org/github.com/reiver/go-uuidv7?status.svg)](https://godoc.org/github.com/reiver/go-uuidv7)

## Import

To import package **uuidv7** use `import` code like the following:

```
import "github.com/reiver/go-uuidv7"
```

## Installation

To install package **uuidv7** do the following:

```
GOPROXY=direct go get github.com/reiver/go-uuidv7
```
